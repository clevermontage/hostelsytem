CHAPTER ONE

INTRODUCTION

The Hostel Booking System will be a web-based system developed to help students book hostel rooms online easily and efficiently. The system will be developed by a group of students with the aim of reducing the difficulties experienced during manual hostel booking processes. In many institutions, students move from one hostel to another looking for vacant rooms, which wastes time and creates congestion. The proposed system will simplify the booking process by allowing students to access hostel services online.

The Hostel Booking System will contain two main users namely the student and the administrator. The student will be able to view available rooms and make bookings through the system. The administrator will manage the system by viewing bookings, approving bookings, adding rooms, and deleting rooms. The system will improve efficiency, save time, and provide better management of hostel records.

The system will be developed using web technologies that will provide an interactive and user-friendly environment. The Hostel Booking System will ensure proper storage and management of booking information.

Background of the Study

With the advancement of information technology, many organisations and institutions are shifting from manual systems to computerised systems. Hostel management is one of the important areas that require automation because many students require accommodation every academic year. Manual booking methods are slow, insecure, and difficult to manage.

The Hostel Booking System will therefore be developed to solve problems associated with manual hostel allocation. The system will allow students to access hostel services online without unnecessary movement or paperwork. Administrators will also be able to manage hostel records efficiently using the system dashboard.

Problem Statement

Many institutions still use manual methods to manage hostel bookings. This causes problems such as loss of records, delays in booking, overbooking of rooms, and difficulty in tracking student allocations. Students also waste time searching for available rooms physically. Therefore, there will be a need to develop a computerised Hostel Booking System that will simplify the booking and management process.

Objectives of the Study

The main objective of the study will be to develop a Hostel Booking System that will help students book hostel rooms online and enable administrators to manage hostel operations effectively.

The specific objectives of the study will be to develop a system that will allow students to book rooms online, to enable administrators to view and approve bookings, to allow administrators to add and delete hostel rooms, and to improve the management of hostel accommodation records.

Scope of the Study

The study will focus on the development of a web-based Hostel Booking System. The system will mainly concentrate on hostel booking and room management functionalities. The users involved in the system will be the student and the administrator. The student will perform booking activities while the administrator will manage hostel information and student bookings.

Significance of the Study

The Hostel Booking System will be important because it will improve efficiency in hostel management. Students will be able to book rooms conveniently without travelling long distances. The system will also reduce paperwork and improve record keeping. Administrators will benefit from easier monitoring and management of hostel bookings. The system will further save time and improve communication between students and administrators.

 CHAPTER THREE

 SYSTEM ANALYSIS AND DESIGN

 Existing System

The existing hostel booking process mainly uses manual methods. Students physically visit hostel offices to inquire about available rooms. Records are stored on paper files, making it difficult to track room occupancy and student details. The manual system is slow and prone to errors such as duplicate bookings and loss of information.

 Proposed System

The proposed Hostel Booking System will be an online platform that will automate hostel management activities. The system will allow students to log into the system, view available rooms, and make bookings. The administrator will manage room details and booking approvals through the admin dashboard.

 System Users

The system will have two main users namely the student and the administrator.

The student will be responsible for viewing available rooms and booking hostel rooms through the system.

The administrator will manage the system by viewing bookings, approving bookings, adding rooms, and deleting rooms.

 Functional Requirements

The student will be able to register and log into the system. The student will also be able to view available rooms and book a room successfully.

The administrator will be able to log into the admin dashboard. The administrator will further be able to add hostel rooms, delete rooms, view student bookings, and approve bookings.

 Non-Functional Requirements

The system will be secure to protect user information. The system will also be reliable and easy to use. In addition, the system will have a fast response time and support proper database storage.

System Design

The system will be designed using a client-server architecture. Students and administrators will interact with the system through web pages connected to a database server. The database will store information about students, rooms, and bookings.

CHAPTER FOUR

SYSTEM IMPLEMENTATION

The Hostel Booking System will be implemented using different web development technologies. HTML will be used to design the structure of the web pages while CSS will be used for styling and improving the appearance of the system. JavaScript will be used to add interactivity to the system. PHP will be used as the server-side programming language while MySQL will be used for database management.

The system will consist of different modules including the student module and the administrator module. The student module will allow students to view rooms and make bookings. The administrator module will allow management of rooms and approval of bookings.

The database will be designed to store student details, room information, and booking records. Proper validation techniques will be implemented to ensure accurate data entry.

 System Functionalities

Student Functionalities

The student will log into the system using login credentials. After logging in, the student will view available hostel rooms displayed on the system. The student will then book a preferred room. The booking details will be stored in the database awaiting administrator approval.

Administrator Functionalities

The administrator will log into the admin dashboard to manage hostel operations. The administrator will add new rooms to the system and delete rooms that are no longer available. The administrator will also view all bookings made by students and approve valid bookings.
